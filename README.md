# MadWorld 한국어 패치

Nintendo Wii판 **MadWorld (USA)**용 비공식 한국어 패치입니다.

이 저장소의 배포 파일은 **`MadWorld_Korean_Patcher.exe` 하나만 사용**합니다. 별도의 패치 데이터나 추가 프로그램을 받을 필요가 없습니다.

## 지원 버전

- 게임: **MadWorld (USA)**
- 플랫폼: **Nintendo Wii**
- Game ID: **RZZE8P**
- 입력 파일: 원본 **RVZ**

다른 지역판이나 이미 수정된 게임 파일은 정상적으로 패치되지 않을 수 있습니다.

## 사용 방법

1. `MadWorld_Korean_Patcher.exe`를 실행합니다.
2. **MadWorld USA 원본 RVZ**를 선택합니다.
3. 출력할 RVZ 경로를 지정합니다.
4. **한글패치 적용**을 누릅니다.
5. 작업이 끝나면 새 한국어 패치 RVZ가 생성됩니다.

원본 RVZ는 직접 수정하지 않습니다.

## 문제 발생 시

패치가 진행되지 않는 경우 다음을 먼저 확인하세요.

- USA판인지 확인
- Game ID가 `RZZE8P`인지 확인
- 원본 RVZ가 손상되지 않았는지 확인
